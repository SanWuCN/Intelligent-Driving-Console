## 02 车 V2X 外设兼容修复（2026-09-17）

- V2X UDP 接收不再要求本机配置固定地址 `192.168.20.200`；注册消息使用系统到 OBU 的路由对应的本机地址。
- 缺少 `/dev/video10` 或摄像头没有图像时跳过图像处理，保留底盘与雷达处理。
- 初始化可选外设指针，退出前等待 V2X 线程结束；未取得注册标识时不发送心跳。
- 配套控制台通过 `/ctrl_fb` 实时反馈判断底盘状态，缺少反馈时禁止启动循迹。
- 前车预警仅使用 2 秒内有效的本车和目标坐标；空目标列表、零坐标、无效定位和过期数据不触发距离预警。
- 前车预警只在状态变化时发出信号，避免反复刷新窗口；坐标接收和刹车预警计算在同一线程执行。
