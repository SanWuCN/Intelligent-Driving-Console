# 智能驾驶控制台设计与交互规格

## 信息架构

- 顶栏：学校标识、产品名称、连接状态、控制解锁、常驻紧急停止。
- 左栏：六步启动流程，完成、当前、等待、阻止和运行中五种状态。
- 中栏：真实 CSV 航迹预览与车载桌面/RViz 流切换。
- 右栏：ROS 模块状态、PCD/CSV 文件白名单选择和下一步主操作。
- 底部：结构化操作日志与车端时间。

## 设计令牌

- 学校主蓝：`#145bb8`；强交互蓝：`#0d4da2`。
- 成功：`#15a95b`；警告：`#d98a00`；危险：`#e63f36`。
- 页面背景：`#eef3f8`；真实白色面板：`#ffffff`；边框：`#d5e0eb`。
- 圆角仅 5–8px，使用 1px 边框和低强度阴影，不使用渐变或玻璃拟态。
- 控件最小触控尺寸 44px；所有图标来自 Lucide，装饰图标隐藏于辅助技术。

## 安全交互

- 所有写操作使用 `X-Control-Token`，令牌仅保存在 `sessionStorage`。
- 紧急停止不要求令牌，停止控制节点并向 `/ctrl_cmd` 连续发布零速指令。
- 启动循迹必须逐项确认场地、物理急停和定位/路径状态。
- 后端只接受固定动作与数据目录内的文件名，拒绝任意命令和路径穿越。
- 服务启动后只读监控，不自动启动车辆节点，不自动发送运动指令。
